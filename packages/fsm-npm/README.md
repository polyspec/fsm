# @polyspec/fsm-npm

[한국어](README.ko.md)

The npm consumer of fsm (`docs/plans/fsm-v1.md`, C-2). The package is private and is a test bed: it is not published.
It shows how the generated npm code of a fsm definition is used, and it checks that code against the conformance vectors.

- `src/`: generated by `fsm-gen gen --kind npm` (do not edit). Each machine has `<machine>.js` and `<machine>.d.ts`; `fsm.js`
  holds the `Error` class and the `Code` constants; `index.js` exports one namespace per machine and `fsm`.
- `tests/vectors.mjs`: the vector cases of every machine, generated by `fsm-gen vectors --kind npm`.
- `tests/conformance.test.mjs`: one test per vector case, named `test_<feature>__<id>`, which asserts the result of the
  generated function or its error code.
- `examples/persist.mjs`: the persistence pattern of `docs/spec/fsm.md` (B-4) on SQLite with polyspec orm. The persist
  cases run it.
- `examples/model/`: the orm model generated from the root `schema/persist.dbs`.

From this directory: `make install` installs the pinned dependencies, `make gen` regenerates the files above, and `make test`
runs the tests through `scripts/kit/run-tests.mjs`. The root `make gen-check` checks that the generated files are current.
