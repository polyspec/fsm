# github.com/polyspec/status-go

[한국어](README.ko.md)

The go consumer of status (`docs/plans/status-v1.md`, C-2). The module is private and is a test bed: it is not published.
It shows how the generated go code of a status definition is used, and it checks that code against the conformance vectors.

- `src/`: generated by `status-gen gen --kind go` (do not edit). `order/order.go` is the machine and `status/status.go` holds the
  `Error` type and the `Code*` constants that every machine returns.
- `tests/vectors_test.go`: the vector cases of every machine, generated by `status-gen vectors --kind go`.
- `tests/conformance_test.go`: one subtest per vector case, named `test_<feature>__<id>`, which asserts the result of the
  generated function or its error code.
- `examples/persist.go`: the persistence pattern of `docs/spec/status.md` (B-4) on SQLite with polyspec orm. The persist
  cases run it.
- `examples/model/`: the orm model generated from the root `schema/persist.dbs` by `go tool orm-gen`.

From this directory: `make install` downloads the modules that `go.mod` and `go.sum` name, `make gen` regenerates the files
above, and `make test` runs the tests through `scripts/kit/run-tests.mjs` with `GOPROXY=off`. The root `make gen-check` checks
that the generated files are current.
